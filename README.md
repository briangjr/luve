# Luxe Arcade — Phase 1, version 0.1

A mobile-first, static HTML/CSS/JS prototype. Open `index.html` locally, or deploy the folder to Netlify / GitHub Pages. No build step or dependencies.

## Included
- Luxe Arcade dark/neon design, navigation, loading-free home screen
- Playable single-hand blackjack: betting, hit, stand, double, dealer draws to 17, blackjack 3:2, push
- Fictional chips separate from lifestyle cash
- LocalStorage save/reset
- Placeholder screens for golf, lifestyle, and shop

## Four-phase plan
1. Core interface + functional blackjack (this package; five-seat presentation not yet implemented)
2. Golf hole 1, touch aiming/physics, then nine holes and easy/hard modes
3. Lifestyle/shop economy, bedroom/closet, cars/garage, houses and saving
4. Polish: five-seat blackjack visuals, zoom transitions, image assets, audio, mobile testing

No real-money wagering, payment system, or cash-out. Assets are CSS-based placeholders; approved AI artwork has not been converted into layered assets.
