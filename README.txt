LUX v0.6.3 — Collectibles & Racing Update

This ZIP contains ONLY changed/new files since the previous v0.6.2.3 patch. It is not a standalone site.

INSTALL:
1. Extract the ZIP.
2. Upload its files to the ROOT of your existing LUX GitHub repository, preserving the assets/ folder path.
3. Replace matching filenames. Do not delete other files.
4. Wait for Netlify redeploy, then fully close and reopen the home-screen app (or clear cached page assets if necessary).

CHANGES:
- Get Paid first-click fix: six long rectangular buttons on first entry, with click handler routed to the new menu.
- Roulette/Cornhole game-launch export retained from prior fix.
- Collectibles: newly redesigned portrait shop, LUX branded products, NFL/NBA selector, Fat Pack 10 cards / 3 inserts, Value/Blaster 50 cards / 8 inserts, Mega 100 cards / 17 inserts, Hobby 120 cards / 25 inserts / 1 guaranteed autograph. Mega/Hobby counts are provisional until you provide desired contents.
- Pack reveals cards one by one; front/back flip; persistent collection; sell for fictional LUX cash. Uses existing shared cash balance. Values and card artwork are fictional, not real card scans or market prices.
- New AI-created LUX-branded hero product image (assets/lux-collectibles-shop.webp). Cleaner dark stadium design.
- Street Racing: portrait phone rotates the game surface to landscape, night-city road canvas, steering, acceleration, rare traffic, finish rewards, and selection from cars owned. Existing finance and garage screens preserved.
- Cache-busting references and dedicated CSS for new layouts.

TEST STATUS: Node syntax checks and ZIP integrity passed. The game has NOT been tested in a real mobile Safari session; visual and interaction bugs may remain. No saved-game reset intended.
